# Datasets

The notebooks use a mix of **synthetic data** (generated on the fly by
`src/data.py`) and **real public datasets**.

Raw datasets are not committed to git — see below for how to obtain each one.

---

## Synthetic Data (No Download Required)

Most notebooks default to synthetic data generated by `src.data`:

```python
from src.data import generate_daily_sales
sales = generate_daily_sales(n_days=730)
```

This makes every notebook reproducible without external dependencies.

## Public Datasets

### 1. M5 Forecasting — Accuracy

- **Source:** [Kaggle competition](https://www.kaggle.com/competitions/m5-forecasting-accuracy/data)
- **Used in:** Notebooks 6-10
- **Size:** ~300 MB
- **Description:** Hierarchical sales data from Walmart across 3,049 products,
  10 stores, 3 states. The de-facto benchmark dataset for demand forecasting.

Download to `data/raw/m5/`:
```bash
kaggle competitions download -c m5-forecasting-accuracy -p data/raw/m5/
unzip data/raw/m5/m5-forecasting-accuracy.zip -d data/raw/m5/
```

### 2. Store Sales — Time Series Forecasting

- **Source:** [Kaggle competition](https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data)
- **Used in:** Notebooks 4-5
- **Size:** ~30 MB
- **Description:** Store sales from Corporación Favorita (Ecuador), useful for
  imputation and outlier detection examples with real-world messiness.

```bash
kaggle competitions download -c store-sales-time-series-forecasting -p data/raw/store-sales/
unzip data/raw/store-sales/store-sales-time-series-forecasting.zip -d data/raw/store-sales/
```

### 3. ETT (Electricity Transformer Temperature)

- **Source:** [GitHub — zhouhaoyi/ETDataset](https://github.com/zhouhaoyi/ETDataset)
- **Used in:** Notebooks 3, 7
- **Size:** ~10 MB
- **Description:** High-frequency sensor data for oil transformers — good for
  decomposition and multi-variate feature engineering examples.

```bash
git clone https://github.com/zhouhaoyi/ETDataset.git data/raw/ett/
```

### 4. Wikipedia Web Traffic

- **Source:** [Kaggle](https://www.kaggle.com/c/web-traffic-time-series-forecasting)
- **Used in:** Notebooks 8-9
- **Size:** ~250 MB
- **Description:** Daily page views for ~145k Wikipedia articles. Excellent
  for demonstrating trend + seasonality feature engineering at scale.

```bash
kaggle competitions download -c web-traffic-time-series-forecasting -p data/raw/wiki-traffic/
unzip data/raw/wiki-traffic/web-traffic-time-series-forecasting.zip -d data/raw/wiki-traffic/
```

## Kaggle API Setup

To use the `kaggle` CLI commands above:

1. Install: `pip install kaggle`
2. Get your API token from [kaggle.com/account](https://www.kaggle.com/account)
3. Place it at `~/.kaggle/kaggle.json` (Unix) or `%USERPROFILE%\.kaggle\kaggle.json` (Windows)
4. `chmod 600 ~/.kaggle/kaggle.json` on Unix
